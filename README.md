# X Follow Manager

用于 X/Twitter 的本地用户脚本：识别互关与未回关账号，读取页面自身网络响应中的用户数据，并提供受控的条件取关与自动回关。

## 功能

- `/following`：隐藏互关、筛选未回关、显示网络响应中的关注者/关注中数量。
- `/followers`：识别尚未回关的关注者，并手动点击“执行回关”。
- 白名单、认证/保护账号排除、简介关键词条件。
- 默认预览、逐项勾选、每日上限和操作间隔。
- 数据只在当前浏览器本地处理，不发送到第三方服务。

## 安装

使用 Tampermonkey、Violentmonkey 或 Userscripts 新建脚本，将 `x-follow-manager.user.js` 全文粘贴进去。安装后刷新 X 页面。

## 使用

在 X 的“正在关注”或“关注者”页面打开脚本面板。脚本会优先解析 X 当前页面的 GraphQL 响应，无法解析时回退到 DOM。自动回关默认关闭，需要手动开启并点击“执行回关”。

## 安全说明

取关和回关都会改变账号状态。脚本不会调用 X 私有 API 直接写入关系，只通过页面上的原生按钮执行；仍建议低频、少量操作，并先使用预览和白名单。
